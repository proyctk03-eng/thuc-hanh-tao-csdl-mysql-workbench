🛠️ Cách 1: Tạo CSDL Sử Dụng Giao Diện Đồ Họa (GUI Wizard)

  1. Bật MySQL Workbench và đăng nhập vào kết nối Local instance 3306 (user: root).
  2. Trên thanh công cụ Toolbar, click vào biểu tượng "Create a new schema in the connected server" (hình trụ CSDL có dấu cộng).
  3. Tại form thiết lập:
    • Name: Nhập my_database1
    • Charset: Chọn utf8mb4 (hỗ trợ tiếng Việt đầy đủ)
    • Collation: Chọn Default Collation (utf8mb4_unicode_ci)
  4. Nhấn nút Apply ở góc dưới bên phải.
  5. Cửa sổ Review Script hiện ra câu lệnh sinh tự động:
    CREATE SCHEMA `my_database1` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci ;
  6. Tiếp tục nhấn Apply rồi nhấn Finish để hoàn tất tạo CSDL mới.

⚡ Cách 2: Tạo CSDL Sử Dụng Câu Lệnh SQL (Query Editor)

  1. Trong cửa sổ MySQL Workbench, nhấn chọn biểu tượng New Query Tab hoặc nhấn tổ hợp phím Ctrl + T.
  2. Tại cửa sổ soạn thảo mới, nhập câu lệnh theo yêu cầu đề bài:
    CREATE DATABASE `my_database1`;
  3. Nhấn biểu tượng tia sét (Execute) hoặc tổ hợp phím Ctrl + Enter để chạy lệnh.
  4. Kiểm tra panel Action Output ở góc dưới: Xuất hiện dấu tích xanh [OK] CREATE DATABASE my_database1 - 1 row(s) affected.
  5. Nhấn nút Refresh ở mục SCHEMAS, CSDL my_database1 đã được tạo thành công!

📊 Mở Rộng: Tạo Bảng & Kiểm Tra Dữ Liệu

Kịch bản mở rộng quản lý sinh viên và phòng ban trong CSDL my_database1:

-- Kích hoạt CSDL vừa tạo
USE `my_database1`;

-- Xem dữ liệu sinh viên kết hợp JOIN phòng ban
SELECT s.`student_code`, s.`full_name`, s.`email`, d.`dept_name`
FROM `students` s
JOIN `departments` d ON s.`dept_id` = d.`dept_id`;
